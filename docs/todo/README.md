# Open experiments and qualification

The evolved-lives, sensor-v4, canonical-distillation, saved-brain and inspector feature work has been implemented. Its [original implementation plan](archive/evolved-lives-sensors-distillation-plan.md) is archived; the old stage checklists and branch instructions are historical.

- [PPO learning qualification](ppo-learning-qualification.md) is a separate proposed empirical study of the already implemented PPO trainer. It does not imply that the PPO reward or action-policy repair is incomplete.

[Performance and capacity results](../performance/README.md), including [sensor-v4 measurements](../performance/sensor-v4/README.md) and [distillation qualification](../performance/distillation/README.md), document tested limits, failed gates and results that have not yet been demonstrated. Any new optimization or broader qualification should be explicitly scoped rather than reopening a completed implementation project.

Completed project documents are retained in [this archive](archive/) and [the historical project archive](../archive/).
