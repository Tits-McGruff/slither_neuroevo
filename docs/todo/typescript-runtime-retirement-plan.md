Owner-approved implementation scope, 2026-10-10. ADR 0003 records the archive.

1. Verify/publish the combined-source branch and annotated tag before edits.
2. Extract wire types, immutable graph defaults and `buildLargeBrainGraph`;
   retain browser presentation/settings, pure parameter formulas and preferences.
3. Remove TS authority/neural execution, reference server/persistence/pool,
   standalone N-API kernels and simulator-dependent scripts/tests.
4. Keep original-file import/direct export, native legacy readers and source
   identity; preserve frozen expectations and provenance. Warn on neutral old
   config keys, reject active/malformed settings and removed flags/numeric resume.
5. Replace reference acceptance/security/performance with actual native contracts;
   rebuild category/native-required/dependency guards. Preserve UI rate <=60 and
   CPU-normalized Rust worker defaults. Update active documentation.
6. Validate Windows, focused Oxygen/Linux, pre-cleanup checkpoint compatible-build
   recovery, native surface, client/storage/graph/LAN, Rust and all JS categories.
   Deliver through reviewed PR and passing required CI.

No owner files/data/config/services or historical fixture bytes are deleted.
Gameplay/numerics/worker policy/wire/checkpoint/recovery contracts stay unchanged.
Dirty owner work stays untouched in its checkout; implementation then uses a
separate worktree. Retained Rust experimental names and deferred follow-ups are
out of scope. Record compact factual results in the existing implementation log.
